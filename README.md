# Cut!

> Plataforma de streaming de filmes e séries integrada a uma rede social para cinéfilos.

O **Cut!** permite explorar catálogos de filmes e séries, assistir a produções em um player dedicado e interagir com amigos por meio de reviews com avaliações em estrelas, comentários e conexões sociais.

---

## Funcionalidades

- **Catálogo & Streaming:**
  - Navegação por gêneros (Ação, Comédia, Drama, Ficção, etc.) e recomendações personalizadas.
  - Página de detalhes do título com metadados, sinopse, classificação indicativa e nota IMDb.
  - Player de vídeo dedicado para reprodução contínua.

- **Camada Social:**
  - Feed integrado com publicações de amigos e resenhas de filmes.
  - Sistema de avaliação por estrelas (1 a 5), fotos e suporte a emojis.
  - Interações em tempo real: curtir postagens, seguir usuários e visualizar perfis customizados.

---

## Tecnologias Utilizadas

- **Front-end:** React 18, Vite, React Router DOM v6, Lucide React
- **Back-end:** Node.js, Express, CORS
- **Banco de Dados & Autenticação:** Firebase (Firestore & Auth)

## Como Executar o Projeto

### Pré-requisitos
- Node.js (v18+)
- npm ou yarn

### 1. Clonar o repositório
```bash
git clone https://github.com/laryaderno/cut-.git
cd cut-

```

### 2. Instalar as dependências

```bash
npm install

```

### 3. Rodar a aplicação

* **Front-end (React/Vite):**

```bash
npm run dev

```


* **Back-end (Servidor Express):**
```bash
node server.js

```
